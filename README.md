# Cathode

CRT emulation for the web: a WebGL2 library (`js/`, see [js/README.md](js/README.md)), a side-by-side
comparison app (`js/compare/`), a benchmark page (`js/benchmark/`), and a YouTube browser extension (`js/extension/`).
Shaders from [Toddler-Boy/CRTEmulation-Data](https://github.com/Toddler-Boy/CRTEmulation-Data) (`assets/crt/`).
